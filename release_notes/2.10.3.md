## English

On Windows, a slide with a background video now shows the video, including a title. The projection on another screen keeps the right size when that screen uses a different scale, such as a 4K television. Closing Salmia after a presentation quits the program.

On Ubuntu and Debian, the `.deb` package installs the decoder that background video needs. If a video is still black, install `gstreamer1.0-libav` and open Salmia again. If a video stutters, Salmia asks you to set the projection screen to 1920×1080.
